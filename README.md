## **ЗАДАНИЕ: "СИМУЛЯТОР КОФЕЙНИ"**

Ты создаёшь систему управления небольшой кофейней. Нужно учитывать меню, заказы клиентов, ингредиенты и выручку.

---

### Что нужно реализовать:

#### **1. Класс `MenuItem` (Позиция меню)**

- Название напитка
- Цена
- Список ингредиентов (словарь: {ингредиент: количество})
- Время приготовления

**Методы:**

- `get_cost(ingredients)` - рассчитать себестоимость
- `can_make(available_ingredients)` - проверить, можно ли приготовить

---

#### **2. Класс `Order` (Заказ)**

- Номер заказа
- Клиент
- Список напитков
- Статус (новый/готов/выдан)
- Общая сумма

**Методы:**

- `add_drink(menu_item)` - добавить напиток
- `calculate_total()` - посчитать сумму
- `mark_ready()` - отметить готовым
- `mark_completed()` - отметить выданным

---

#### **3. Класс `CoffeeShop` (Кофейня)**

- Название
- Меню (список `MenuItem`)
- Заказы (список `Order`)
- Склад ингредиентов (словарь)
- Выручка

**Методы:**

- `add_menu_item(item)` - добавить в меню
- `create_order(client_name)` - создать заказ
- `process_order(order_number)` - обработать заказ (списать ингредиенты)
- `get_revenue()` - показать выручку
- `show_menu()` - показать меню
- `show_orders()` - показать все заказы
- `check_ingredients()` - проверить остатки

### Пример работы кода:
```python
# Создание кофейни
shop = CoffeeShop("Уютное место")

# Добавление позиций меню
shop.add_menu_item(MenuItem("Эспрессо", 150, {"кофе": 18, "вода": 30}, 2))
shop.add_menu_item(MenuItem("Капучино", 250, {"кофе": 18, "молоко": 150, "вода": 30}, 4))
shop.add_menu_item(MenuItem("Латте", 280, {"кофе": 18, "молоко": 200, "вода": 30}, 5))

# Создание заказа
order1 = shop.create_order("Иван")
order1.add_drink(shop.menu[0])  # Эспрессо
order1.add_drink(shop.menu[1])  # Капучино

# Обработка заказа
shop.process_order(1)
# Вывод: Заказ #1 готов! Сумма: 400 руб.

# Проверка остатков
shop.check_ingredients()
# Вывод: кофе: 500г, молоко: 2000мл, вода: 5000мл
```
